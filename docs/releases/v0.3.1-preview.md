# v0.3.1 preview

This preview improves setup guidance, milestone feedback, and recovery. Its
binaries and host adapters share version `0.3.1`.

Changes since v0.3.0:

- Setup explains host readiness and the prerequisites for local test evidence.
- Recovery initialization and milestone claim outcomes provide clearer guidance.
- Recovery bundles preserve per-project integration selections. Version 0.3.1
  can restore older bundles without selections, leaving them unset. Older binaries,
  including v0.3.0, reject bundles containing the new selection files; restore
  those bundles with v0.3.1 or a newer binary.

## Installing the preview

Use the tagged installer and explicitly select the preview version:

```bash
curl -fsSL https://raw.githubusercontent.com/MeSH-Inc/agentspeedrun/v0.3.1/install.sh | SPEEDRUN_VERSION=v0.3.1 SPEEDRUN_SKIP_ATTESTATION=1 sh
```

The preview assets are locally built and have no build provenance attestations.
The installer still verifies their published checksums; the command skips only
attestation verification for this preview.

Install the matching preview VSIX from the release assets for VS Code. Zed is
available as a development extension; see the repository instructions.

## Upgrading from v0.2.0

Install the preview over v0.2.0, then run `speedrun setup` and `speedrun capture`
to check the host configuration. The release upgrade harness exercises signed
history, project trust and pending offline delivery from v0.2.0. The v0.1 data
format is retired; see [v0.2 design decisions](../V0.2.md).

## Verification and limitations

The accompanying `VERIFICATION.md` records the candidate commit, checks and
platform environments; `SHA256SUMS` records the asset checksums. The Zed
extension does not capture its own agent prompts. Prompt text redaction is
best effort; use metadata-only capture when text should not be recorded.
