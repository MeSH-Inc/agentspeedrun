# v0.3.0 preview

This preview adds guided setup, capture diagnostics and milestone actions to the
local timing workflow. Its binaries and host adapters share version `0.3.0`.

- Guided `speedrun setup` configures a host, project and capture preference;
  `speedrun capture` helps diagnose whether prompts arrive.
- Milestone actions and evidence selection guide claims and verification.
- `speedrun local-test -- <command> [args...]` records a local test result;
  terminal and editor pickers can attach it as milestone evidence.
- Prompt capture supports metadata-only mode, and offline delivery has durable
  recovery and diagnostics for rejected entries.
- The CLI and editor integrations provide improved recovery guidance and
  project status. Backups can preserve the event log while the daemon runs.

## Installing after publication

Use the tagged installer and explicitly select the preview version:

```bash
curl -fsSL https://raw.githubusercontent.com/MeSH-Inc/agentspeedrun/v0.3.0/install.sh | SPEEDRUN_VERSION=v0.3.0 SPEEDRUN_SKIP_ATTESTATION=1 sh
```

The preview assets are locally built and have no build provenance attestations.
The installer still verifies their published checksums; the command skips only
attestation verification for this preview.

Install the matching preview VSIX from the release assets for VS Code. Zed is
available as a development extension; see the repository instructions.

## Upgrading from v0.2.0

Install the preview over v0.2.0, then run `speedrun setup` and `speedrun capture`
to check the host configuration. The release upgrade harness exercises signed
history, project trust and pending offline delivery from v0.2.0. The v0.1 data
format is retired; see [v0.2 design decisions](../V0.2.md).

## Verification and limitations

The accompanying `VERIFICATION.md` records the candidate commit, checks and
platform environments; `SHA256SUMS` records the asset checksums. macOS Intel
and Linux x86_64 checks run under emulation; native x86_64 hardware has not
been verified. The Zed
extension does not capture its own agent prompts. Prompt text redaction is
best effort; use metadata-only capture when text should not be recorded.
