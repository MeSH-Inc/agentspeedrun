# v0.3.2 preview

This preview updates the OpenCode adapter for OpenCode v2. Its binaries and host
adapters share version `0.3.2`.

Changes since v0.3.1:

- The OpenCode adapter uses the v2 plugin API to capture human prompts, end turns
  when session execution completes, and expose milestone tools. OpenCode v1 is
  no longer supported by this adapter. Restart OpenCode after upgrading it.
- Copilot CLI project hooks require a trusted workspace. Complete Copilot's
  workspace trust flow before testing project-scope capture; permitting tool
  paths alone does not enable project hooks.

## Installing the preview

Use the tagged installer and explicitly select the preview version:

```bash
curl -fsSL https://raw.githubusercontent.com/MeSH-Inc/agentspeedrun/v0.3.2/install.sh | SPEEDRUN_VERSION=v0.3.2 SPEEDRUN_SKIP_ATTESTATION=1 sh
```

The preview assets are locally built and have no build provenance attestations.
The installer still verifies their published checksums; the command skips only
attestation verification for this preview. Install the matching preview VSIX
from the release assets for VS Code. Zed is available as a development extension.

## Upgrading

Install the preview over the existing installation, then run `speedrun setup`
and `speedrun capture` to check host configuration. Reinstall the OpenCode
adapter with `speedrun setup opencode` (or the project-scope option) and restart
OpenCode. The v0.1 data format is retired; see [v0.2 design decisions](../V0.2.md).

## Verification and limitations

The accompanying `VERIFICATION.md` records the candidate commit, checks,
platform environments, and coverage gaps; `SHA256SUMS` records asset checksums.
Host authentication or provider failures leave the affected live paths
unverified. See [host verification](../HOST_VERIFICATION.md) for host-specific
results; fixture tests do not establish live-host coverage.

OpenCode active-turn tracking is in memory. Hot-reloading the plugin during a
turn does not transfer that state and was not covered by the live checks. The
Zed extension does not capture its own agent prompts. Prompt text redaction is
best effort; use metadata-only capture when text should not be recorded.
